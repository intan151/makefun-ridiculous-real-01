One deterministic Python program (standard library only) writes one sentence
— 138 characters — pitching a bizarre startup idea that sounds like a joke
until the business logic lands, to `/output/entry.txt`.

> We sell naming rights to potholes: a local shop sponsors one, the city
> fixes it, and your logo sits where every driver is already staring.

Run it:

```sh
python3 main.py
```

It writes a single line of text to `/output/entry.txt`.
